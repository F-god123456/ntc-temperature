# NTC测温项目 (STM32F030K6T6)

基于 **STM32F030K6T6** 微控制器（48MHz，32KB Flash，4KB SRAM）的 NTC 热敏电阻温度测量项目。使用 12 位 ADC 采集分压电压，查表换算温度，通过串口输出。

## 功能特性

- **NTC 温度测量**：支持正温 0℃ ~ 125℃ 和负温 -1℃ ~ -54℃
- **ADC 多采平均**：每次测量连续采集 10 次 ADC 值取平均，提高稳定性
- **串口输出**：9600bps、8N1，每秒输出一次当前温度值（通过 SysTick 定时）
- **查表转换**：内置温度-电阻对应表格，电阻值以 10Ω 为单位（如 25℃ → 1000 → 10.00kΩ），免去复杂公式计算
- **负温处理**：通过标志位 `NTC_tempFlag` 标识负温，输出时附加负号
- **LED 指示**：板载 LED 驱动（GPIOB.1，推挽输出）

| 振荡器 | HSI 8MHz |

## 硬件资源

| 外设 | 引脚 | 说明 |
|------|------|------|
| ADC1 | PA0 | NTC 电压采集（12位，软件触发） |
| USART1 | PA9(TX) / PA10(RX) | 串口通讯 9600bps (AF1) |
| LED | PB1 | 板载指示灯（推挽输出） |
| NTC 上拉电阻 | - | 10kΩ 接 3.3V（NTC 接 GND 侧） |

### NTC 电路

```
3.3V ── 10kΩ ──┬── PA0(ADC) ── NTC ── GND
               └── 测量点
```

## 使用方法

1. 使用 Keil MDK 打开 `User/BY_STM32F030K6_Board_Lib.uvprojx`
2. 编译下载至 STM32F030K6T6 开发板
3. 打开串口助手（9600, 8N1）查看温度输出

## 串口输出示例

```
NTC temp: 25C      （正温）
NTC temp: -5C      （负温，由标志位控制负号）
```

## 温度测量原理

NTC 热敏电阻（低端）与 10kΩ 电阻（高端）串联分压，ADC 采集中间节点电压，计算 NTC 当前电阻值，再查温度-电阻表格得到对应温度。

### 计算步骤

1. **数字量转电压**

   `V_ADC = (ADC值 / 4096) × 3.3V`

2. **计算 NTC 电阻值**（单位 10Ω）

   `R_NTC = 1000 × V_ADC / (3.3V - V_ADC)`

   结果与温度-电阻表格比较（Ttable 用 10Ω 为单位：1000 = 10.00kΩ）

3. **查表得到温度**

   正温遍历 Ttable[0~125]，负温遍历 FTtable[-1~-54]（表中存储映射值 201~255，减去 200 得实际温度绝对值）

### 关键代码路径

```
main.c → HandleADC() → ADC_ReadChannel(PA0) ×10次取平均
         → 计算 R_NTC → 查 Ttable/FTtable → 返回温度值 + 负温标志
         → printf 输出到串口
```
