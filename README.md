# NTC测温项目 (STM32F030K6T6)

基于 **STM32F030K6T6** 微控制器的 NTC 热敏电阻温度测量项目，使用 ADC 采集电压，查表换算温度，通过串口输出。

## 功能特性

- **NTC 温度测量**：支持正温范围 0℃ ~ 125℃ 和负温范围 -1℃ ~ -54℃
- **ADC 多采平均**：每次测量采集 10 次 ADC 值取平均，提高稳定性
- **串口输出**：9600 波特率，每秒输出一次当前温度值
- **查表转换**：内置温度-电阻对应表格（Ttable 0~125℃，FTtable -1~-54℃），无需复杂计算公式
- **LED 指示**：板载 LED 驱动（GPIOB.1）

## 硬件资源

| 外设 | 引脚 | 说明 |
|------|------|------|
| ADC1 | PA0  | NTC 电压采集 |
| USART1 | PA9/PA10 | 串口通讯 (9600bps) |
| LED | PB1 | 板载指示灯 |
| NTC 串联电阻 | - | 10kΩ 上拉 |

## 使用方法

1. 使用 Keil MDK 打开 `User/BY_STM32F030K6_Board_Lib.uvprojx`
2. 编译下载至 STM32F030K6T6 开发板
3. 打开串口助手（9600, 8N1）查看温度输出

## 串口输出示例

```
NTC temp: 25C
NTC temp: 25C
NTC temp: -5C    (负温显示)
```

## 温度测量原理

NTC 热敏电阻与 10kΩ 电阻串联分压，ADC 采集分压值，计算 NTC 当前电阻值，查温度-电阻表格得到温度值。

- 电压计算：`V_NTC = (ADC值 / 4096) × 3.3V`
- 电阻计算：`R_NTC = 10kΩ × V_NTC / (3.3V - V_NTC)`
